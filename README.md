# ত্রিফুল আরোগ্য নিকেতন - অ্যাপ্লিকেশন ডকুমেন্টেশন

এই ডকুমেন্টটি "ত্রিফুল আরোগ্য নিকেতন" অ্যাপ্লিকেশনটির গঠন, প্রযুক্তি, এবং কার্যকারিতা সম্পর্কে একটি বিস্তারিত বিবরণ প্রদান করে।

---

## ১. ব্যবহৃত প্রধান প্রযুক্তি

*   **ফ্রেমওয়ার্ক:** Next.js (React Framework)
*   **ভাষা:** TypeScript
*   **স্টাইলিং:** Tailwind CSS
*   **UI কম্পোনেন্ট:** ShadCN UI
*   **ডাটাবেস:**
    *   **Primary:** PostgreSQL (via Firebase Data Connect)
    *   **Secondary:** Firebase Firestore (สำหรับ অন্যান্য ডেটা)
*   **অথেন্টিকেশন:** Firebase Authentication
*   **হোস্টিং:** Firebase App Hosting
*   **AI সুবিধা:** Google Genkit (Gemini মডেল)
*   **ভয়েস টাইপিং:** Web Speech API (ব্রাউজার ভিত্তিক)
*   **কুরিয়ার সার্ভিস:** Steadfast Courier API

---

## ২. প্রজেক্টের ফোল্ডার গঠন (Project Structure)

অ্যাপ্লিকেশনটির কোডগুলো একটি সুনির্দিষ্ট ফোল্ডার কাঠামোতে সাজানো হয়েছে, যা নিচে বর্ণনা করা হলো:

*   **`src/app/`**: এটি Next.js অ্যাপ্লিকেশনের মূল কেন্দ্র, যেখানে সমস্ত পেজ এবং লেআউট থাকে।
    *   **`(app)/`**: এই ফোল্ডারে থাকা সমস্ত পেজ ব্যবহারকারী লগইন করার পরেই কেবল অ্যাক্সেস করতে পারে। এটি একটি সুরক্ষিত রুট গ্রুপ।
        *   `dashboard/`: অ্যাপ্লিকেশনের প্রধান ড্যাশবোর্ড।
        *   `entry/`: নতুন রোগী নিবন্ধন করার পেজ।
        *   `search/`: নিবন্ধিত রোগীদের খুঁজে বের করার পেজ।
        *   `dictionary/`: বর্ণমালা অনুযায়ী রোগীদের তালিকা দেখানোর পেজ।
        *   `report/`: দৈনিক, সাপ্তাহিক, মাসিক বা কাস্টম রিপোর্ট তৈরির পেজ।
        *   `slip/`: সকল পেমেন্ট স্লিপ খোঁজার এবং দেখার পেজ।
        *   `prescription/[patientId]/`: নির্দিষ্ট রোগীর জন্য প্রেসক্রিপশন তৈরি বা এডিট করার পেজ।
        *   `ai-summary/`: AI ব্যবহার করে রোগীর অভিযোগ বিশ্লেষণ করার পেজ (AI রেপার্টরি)।
        *   `medicine-instructions/`: ঔষধ খাওয়ার নিয়মাবলী প্রিন্ট করার পেজ।
        *   `clinic-information/`: ক্লিনিকের তথ্য (নাম, ঠিকানা) সেট করার পেজ।
        *   `settings/`: অ্যাপ্লিকেশনের বিভিন্ন সেটিংস (যেমন: থিম, ডেটা এক্সপোর্ট) পরিচালনা করার পেজ।
        *   `courier/`: Steadfast Courier-এর মাধ্যমে পার্সেল এবং অর্ডার পরিচালনা করার পেজ।
    *   **`api/`**: API রুটগুলো এখানে থাকে।
        *   `ai/`: AI flow-গুলোর জন্য API এন্ডপয়েন্ট।
        *   `steadfast/`: Steadfast Courier API সম্পর্কিত এন্ডপয়েন্ট।
        *   `steadfast-webhook/`: Steadfast Courier থেকে স্বয়ংক্রিয়ভাবে স্ট্যাটাস আপডেট গ্রহণ করার জন্য Webhook এন্ডপয়েন্ট।
    *   **`page.tsx`**: এটি অ্যাপ্লিকেশনের প্রধান **লগইন পেজ**।
    *   **`layout.tsx`**: এটি সম্পূর্ণ অ্যাপ্লিকেশনের মূল লেআউট।

*   **`src/components/`**: পুনরায় ব্যবহারযোগ্য UI কম্পונেন্টগুলো এখানে থাকে।
    *   **`shared/`**: বিভিন্ন পেজে ব্যবহৃত সাধারণ কম্পונেন্ট।
    *   **`ui/`**: ShadCN UI লাইব্রেরি থেকে তৈরি করা বেস কম্পונেন্ট (Button, Card, Input ইত্যাদি)।
    *   **`patient/`**, **`slip/`**, **`repertory/`** ইত্যাদি:特定の ফিচার সম্পর্কিত কম্পোনেন্ট।

*   **`src/lib/`**: অ্যাপ্লিকেশনের মূল লজিক, ফাংশন এবং সার্ভিসগুলো এখানে থাকে।
    *   **`firebase.ts`**: Firebase সংযোগ স্থাপন এবং কনফিগারেশনের জন্য ব্যবহৃত হয়।
    *   **`firestoreService.ts`**: Firestore ডাটাবেস সম্পর্কিত ফাংশন।
    *   **`steadfastService.ts`**: Steadfast Courier API-এর সাথে সম্পর্কিত ফাংশন।
    *   **`types.ts`**: TypeScript-এর জন্য বিভিন্ন ডেটা মডেলের (data models) সংজ্ঞা।
    *   **`utils.ts`**: ছোটখাটো সাহায্যকারী ফাংশন।

*   **`src/ai/`**: Genkit এবং AI সম্পর্কিত সমস্ত কোড এখানে রয়েছে।
    *   **`flows/`**: এই ফোল্ডারে AI দ্বারা চালিত বিভিন্ন কার্যকারিতার জন্য ফ্লো (flow) লেখা আছে, যেমন `suggest-remedies.ts`, `homeopathic-assistant-flow.ts` ইত্যাদি।

*   **`dataconnect/`**: Firebase Data Connect-এর কনফিগারেশন।
    *   **`dataconnect.yaml`**: সার্ভিস ও ডাটাবেস কনফিগারেশন। এটি PostgreSQL ডাটাবেসের সাথে সংযোগ স্থাপন করে।
    *   **`schema/`**: ডাটাবেস স্কিমা (schema.gql)।
    *   **`connector/`**: কোয়েরি ও মিউটেশন (queries.gql, mutations.gql)।

*   **`functions/`**: Firebase Functions-এর জন্য সোর্স কোড।

*   **`public/`**: স্ট্যাটিক ফাইল, যেমন ছবি, আইকন ইত্যাদি এখানে রাখা হয়।

*   **`next.config.js`**, **`firebase.json`**, **`package.json`**: প্রজেক্টের বিভিন্ন কনফিগারেশন ফাইল।

## ৩. প্রধান ফিচার এবং কার্যকারিতা

#### ক. লগইন ও ড্যাশবোর্ড
*   **লগইন (`/src/app/page.tsx`):** ব্যবহারকারী ইমেইল/পাসওয়ার্ড বা Google অ্যাকাউন্ট দিয়ে লগইন করতে পারেন।
*   **ড্যাশবোর্ড (`/src/app/(app)/dashboard/page.tsx`):** লগইন করার পর এটিই প্রথম পেজ। এখানে Quick Actions এবং বিভিন্ন কার্যকলাপের সারাংশ দেখা যায়।

#### খ. রোগী ব্যবস্থাপনা
*   **নতুন রোগী ভর্তি ও অনুসন্ধান:** নতুন রোগীর তথ্য নিবন্ধন করা এবং তাদের সহজেই খুঁজে বের করার ব্যবস্থা।

#### গ. চিকিৎসা ও প্রেসক্রিপশন
*   **প্রেসক্রিপশন তৈরি:** রোগীর ভিজিটের উপর ভিত্তি করে প্রেসক্রিপশন তৈরি ও প্রিন্ট করার সুবিধা।
*   **AI রেপার্টরি:** রোগীর লক্ষণ বিস্তারিতভাবে লিখে দিলে, AI সেটি বিশ্লেষণ করে সেরা ঔষধগুলোর একটি তুলনামূলক তালিকা প্রদান করে।

#### ঘ. কুরিয়ার এবং Webhook
*   **কুরিয়ার ম্যানেজমেন্ট:** Steadfast Courier API ব্যবহার করে অ্যাপ থেকে নতুন অর্ডার তৈরি এবং ট্র্যাক করা যায়।
*   **স্বয়ংক্রিয় Webhook:** Steadfast থেকে পাঠানো স্বয়ংক্রিয় নোটিফিকেশন গ্রহণ করে ডাটাবেস আপডেট করা হয়।

#### ঙ. ভয়েস টাইপিং
*   **ভাসমান ভয়েস বাটন:** কীবোর্ডের `V` কী চেপে যেকোনো ইনপুট ফিল্ডে স্বয়ংক্রিয়ভাবে বাংলা টাইপ করার সুবিধা।

## ৪. অ্যাপ্লিকেশন চালানো এবং ডিপ্লয়মেন্ট

*   **লোকাল মেশিনে চালানো:**
    1.  প্রয়োজনীয় প্যাকেজ ইনস্টল: `npm install`
    2.  ডেভেলপমেন্ট সার্ভার চালু: `npm run dev`
    3.  ব্রাউজারে `http://localhost:3000` ভিজিট করুন।

*   **Firebase-এ ডিপ্লয়মেন্ট:**
    *   অ্যাপ্লিকেশনটি `main` ব্রাঞ্চে পুশ করার সাথে সাথেই স্বয়ংক্রিয়ভাবে Firebase App Hosting-এ ডিপ্লয় হয়ে যায়।

## ৫. ভবিষ্যৎ উন্নতির সম্ভাবনা (Future Enhancements)

*   **রোগীর পোর্টাল (Patient Portal):** রোগীদের জন্য একটি নিরাপদ লগইন সিস্টেম, যেখানে তারা তাদের ভিজিটের ইতিহাস ও প্রেসক্রিপশন দেখতে পারবেন।
*   **অনলাইন অ্যাপয়েন্টমেন্ট বুকিং:** রোগীরা অ্যাপ ব্যবহার করে সরাসরি সাক্ষাতের জন্য সময় বুক করতে পারবেন।
*   **ভিজ্যুয়াল ড্যাশবোর্ড:** গ্রাফ এবং চার্ট ব্যবহার করে ক্লিনিকের সার্বিক পারফরম্যান্স সহজে বোঝার ব্যবস্থা।
*   **পূর্ণাঙ্গ ঔষধ ব্যবস্থাপনা:** ঔষধের স্টক, মেয়াদ উত্তীর্ণের তারিখ, এবং রিমাইন্ডার সেট করার সুবিধা।
*   **টেলিমেডিসিন সুবিধা:** ভিডিও কলের মাধ্যমে দূরবর্তী রোগীদের সাথে পরামর্শ করার সুবিধা যুক্ত করা।
